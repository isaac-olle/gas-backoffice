# gas-backoffice — Project Structure

## Overview

Go project following minimal DDD. Three bounded contexts + shared kernel + HTTP server.

```
internal/
├── bounded_contexts/
│   ├── backoffice/     — admins, users, protected_resources, scopes, clients
│   ├── protocol/       — OAuth2/PKCE session
│   └── security/       — key_pairs, admin_assertion_keys, client_assertion_keys, client_secrets
├── server/             — Gin HTTP server, handlers, middlewares, route providers
├── shared/             — shared kernel (buses, domain primitives, errors, logger)
└── flows/              — cross-BC orchestration flows
```

## bounded_contexts — Aggregate layout

> **Terminology**: "aggregate" and "module" are synonymous in this project. Each module is one aggregate within a BC.

Each aggregate follows this exact layout:

```
<bc>/<aggregate>/
├── aggregate_root.go       — struct + constructors (New + FromPrimitives) + mutations
├── primitives.go           — XxxPrimitives struct, OwnershipPrimitives, Ownership VO
├── contracts.go            — Repository interface
├── error_messages.go       — ErrorCode constants (ErrXxxNotFound, etc.)
├── ownership.go            — Ownership VO + NewOwnership + CheckOwnership
├── vos/                    — one file per Value Object
├── domain_services/        — Finders (XxxFinder.Find → wraps repo + nil check)
├── infrastructure/
│   └── postgresql.go       — PostgresXxxRepository
├── mocks/                  — mock Repository (generated by mockery from contracts.go)
└── application/
    ├── _event_handlers/    — domain event handlers
    ├── get/                — query: command.go + service.go
    ├── create/             — command: command.go + service.go
    ├── check_ownership/    — query returning OwnershipPrimitives or ForbiddenError
    └── <other_use_cases>/
```

### New aggregate — files and folders to create

This skill only creates files and folders. When asked for a new aggregate, create all of the following:

**BC layer** (`internal/bounded_contexts/<bc>/<aggregate>/`):
```
├── aggregate_root.go
├── primitives.go
├── contracts.go
├── error_messages.go
├── ownership.go
├── vos/                         (empty dir, add VOs as needed)
├── domain_services/
│   └── <aggregate>_finder.go
├── infrastructure/
│   └── postgresql.go
├── mocks/                       (generated by mockery — run after creating contracts.go)
└── application/
    ├── check_ownership/
    │   ├── query.go
    │   └── service.go
    ├── create/
    │   ├── command.go
    │   └── service.go
    ├── get/
    │   ├── query.go
    │   └── service.go
    ├── update/
    │   ├── command.go
    │   └── service.go
    └── delete/
        ├── command.go
        └── service.go
```

**Server layer**:
```
internal/server/
├── handlers/<aggregate>/
│   ├── handler.go               — Handler struct + NewHandler + one method per action
│   ├── create_<aggregate>.go
│   ├── get_<aggregate>.go
│   ├── update_<aggregate>.go
│   └── delete_<aggregate>.go
└── route_providers/
    └── backoffice_<aggregate>s.go   — registers all CRUD routes
```

After creating `contracts.go`, run mockery:
```bash
mockery --name=Repository --dir=internal/bounded_contexts/<bc>/<aggregate> --output=internal/bounded_contexts/<bc>/<aggregate>/mocks --outpkg=mocks
```

### Two constructors rule
- `NewXxx(rawParams..., ownershipId ids.XxxId)` — real creation, fires domain events
- `FromPrimitives(p XxxPrimitives)` — reconstruction from DB, never fires events

### Use case file structure
Each use case package has exactly two files:
- `command.go` / `query.go` — type constant, struct, NewXxx, Type(), Handler, NewXxxHandler, Handle()
- `service.go` — business logic

### Domain service Finders
Use cases inject `*domain_services.XxxFinder`, not the repository directly.
The finder does `SearchById` + nil check + returns typed NotFoundError.

### check_ownership
Returns `(any, error)` — on success: `OwnershipPrimitives`; on failure: `ForbiddenError`.
Ownership chain: Scope/Endpoint → ProtectedResource → User → Admin; Client → Admin + User.

### PostgreSQL schemas
- `backoffice.*` — admins, users, protected_resources, scopes, clients
- `security.*` — key_pairs, admin_assertion_keys, client_assertion_keys, client_secrets
- `protocol.*` — protocol_sessions, protocol_client_credentials_sessions
- `public.*` — audit_events, outbox_event_bus (shared)

## server — HTTP layer

```
server/
├── server.go               — Gin engine setup, route registration
├── route_providers/
│   ├── backoffice_admins.go   — admin endpoints (/v1/backoffice/admins/...)
│   ├── backoffice_users.go    — tenant endpoints (/v1/backoffice/users/...)
│   ├── backoffice_clients.go  — client endpoints (/v1/backoffice/clients/...)
│   └── protocol.go            — OAuth2 endpoints (/oidc/authorize, /oidc/token)
├── handlers/
│   ├── admins/             — token handler
│   ├── users/              — get, change_name, soft_delete
│   ├── clients/            — create, get, soft_delete, add_flow, add_redirect_uri, ...
│   ├── protected_resources/
│   ├── scopes/
│   ├── protocol/
│   └── helpers/
│       └── extractors.go   — AdminIdFromAuthor, UserIdFromAuthor, ClientIdFromAuthor,
│                             UserOwnershipFromAuthor, UserOwnershipFromContext
└── middlewares/
    ├── access_token.go     — verifies JWT, puts Author in context
    ├── role_middleware.go  — checks vo.Role
    ├── ownership/          — User, Client, ProtectedResource, Scope middlewares
    ├── path_params/        — extracts :user_id, :client_id, etc. into context
    └── system_resource/    — blocks mutations on system resources
```

### Adding a new endpoint — checklist
1. **Handler folder** — create `internal/server/handlers/<aggregate>/` if it doesn't exist yet, with:
   - `handler.go` — `Handler` struct + constructor `NewHandler(deps...)` + one method per action
   - one file per action, e.g. `get_user.go`, `create_user.go` (each contains the HTTP logic for that action)
2. **Route** — register in the appropriate `route_providers/backoffice_*.go`, pointing to the handler method
3. **Middlewares** — add ownership/path_param middlewares as needed in the route chain
4. **Use case** — create `application/<action>/command.go` + `service.go` in the BC

### Identity in handlers
Identity comes from context, never from request body:
- `helpers.AdminIdFromAuthor(ctx)` — admin making the request
- `helpers.UserIdFromAuthor(ctx)` — user making the request
- `helpers.ClientIdFromAuthor(ctx)` — client making the request
- `ids.UserIdFromContext(ctx)` — `:user_id` path param
- `ids.ClientIdFromContext(ctx)` — `:client_id` path param

## shared kernel

```
shared/
├── app_errors/             — AppError, ErrorCode, BadRequestError, NotFoundError, etc.
├── buses/
│   ├── command/            — command.Bus + InMemory impl
│   ├── query/              — query.Bus + InMemory impl
│   └── event/              — InMemoryEventBus (10 goroutine pool) + audit + outbox
├── domain/
│   ├── aggregate/          — AggregateRoot base
│   ├── vo/                 — Author interface, Role, Ownership, SetVo, etc.
│   │   ├── authors/        — AdminAuthor, UserAuthor, ClientAuthor
│   │   └── ids/            — all typed ID structs (AdminId, UserId, etc.)
│   └── criteria/           — Criteria query object
├── events/
│   ├── backoffice/         — domain event types for backoffice BC
│   ├── protocol/           — domain event types for protocol BC
│   └── security/           — domain event types for security BC
└── logger/                 — ZapLoggerAdapter
```

### Error conventions
- Aggregates/VOs: `app_errors.BadRequestError(ErrXxx).WithDescription("...")`
- Infrastructure: `fmt.Errorf(...)` — raw errors, no app_errors
- Services wrap infra errors: `app_errors.InternalError(ErrXxx).WithCause(err)`
- Never return `ErrorCode` directly as `error`

### Author (identity) in context
```go
vo.WithAuthor(ctx, author)              // set
vo.AuthorFromContext[*authors.AdminAuthor](ctx)  // get typed
```
Repositories read author with `vo.AuthorFromContext[vo.Author](ctx)` to write `author_id`/`author_role`.

## flows

Cross-BC orchestration lives in `internal/flows/<flow_name>/`:
```go
type Flow struct { commandBus command.Bus }
type Input struct { ... }
type Output struct { ... }
func (f *Flow) Execute(ctx, input) (Output, error)
```

## Bootstrap

`cmd/api/bootstrap/` wires everything:
- `migrations.go` — applies golang-migrate on startup
- `bootstrap.go` — creates DB pools, buses, repos, use cases, server
